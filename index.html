Title

Small Scale Winch System

Engineering Design & Problem Solving
DateJan–Apr 2026
TypeSolidWorks + Arduino
Sheet1 of 2
3:1Speed mode: 60T motor gear to 20T spool via belt
1:3Power mode: gears reversed for torque
~10–12 N·mEstimated motor output torque (12 V, ~12 W)
10+ kgLoad the winch was able to pull

What

  • Designing a small-scale winch system to lift and lower loads in a controlled manner
  • Focus on mechanical transmission, motor control, and system modelling
  • Developed as a virtual prototype using CAD and microcontroller simulation tools

How

  • Designed the mechanical parts, structure and spool geometry in SolidWorks
  • Built and tested the Arduino motor control logic as a circuit simulation in TinkerCAD
  • Explored gear ratios, torque requirements, and speed control for safe lifting

Features

  • Dual-mode operation. Speed mode: motor (60T gear) drives the spool (20T gear) via belt for higher speed
  • Power mode: gear configuration reversed for increased torque output
  • 12 V DC motor with worm gear for controlled motion and load holding
  • Potentiometer speed control with a dead zone for safe stopping
  • Direction control through an integrated switch system
  • H-bridge for full motor control (direction and speed)

Results

  • Speed mode gear ratio 60T : 20T = 3:1 (speed increase, torque reduction)
  • Power mode gear ratio 20T : 60T = 1:3 (torque increase)
  • Estimated motor output torque ~10–12 N·m (based on 12 V, ~12 W assumption)
  • Able to pull more than 10 kg
  • Consistent pulling force across variable speeds using potentiometer control
  • Effective torque amplification in power mode via gear switching
